# Dexys Works

The Dexys Works product-family website, published with GitHub Pages.

Featured products: Dexys AI, Dexys Code Index, and Dexys Code Factory.

The site uses plain HTML, CSS, and JavaScript. All fonts and images are bundled in `assets/`. Product enquiry links open paulo.cardoso@outlook.com with the product name in the subject.

GitHub Pages serves the repository root. No build step is required. Edit `index.html` to update products and `style.css` to update the design.
